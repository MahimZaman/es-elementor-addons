# Elementor Addons by Condixia

Development scaffold for custom Elementor widgets.

## Installation

1. Place this directory at `wp-content/plugins/es-elementor-addons/`.
2. Use a WordPress development site with Elementor installed. See the implementation status below before activation.

## Implementation status

The entry point references `ESEA\Plugin`, but the plugin class and heading widget files are empty in this snapshot. Keep the plugin inactive until those classes are implemented.
